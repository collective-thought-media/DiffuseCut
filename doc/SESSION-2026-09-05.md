## 1. Integrate in scene: tuning and fixes

The masked-inpaint integrate mode (`builtin-shot-scene-integrate-inpaint-v1`) went through a full tuning pass driven by visual test renders:

- **Denoise inside the subject mask** raised 0.6 → **0.9** (`DEFAULT_INTEGRATE_INPAINT_DENOISE`); mid values leave a translucent, half-formed subject.
- **Mask feather** narrowed 22% → **8%** (`INTEGRATE_MASK_FEATHER_RATIO`); wide feather bands partially denoise and read as ghosting.
- **Headroom** added: mask box is 22% taller than the nominal subject height (`INTEGRATE_SUBJECT_HEADROOM_RATIO`); a hard top edge at head height forces crouching or smeared faces.
- **Character IP-Adapter switched to style transfer** (weight 0.6, end 0.55, `INTEGRATE_IN_SCENE_CHARACTER_PROFILE`); linear mode copied the casting reference's *pose* into every shot (a crouched reference forced a crouch everywhere).
- **Prompt handling**: integrate mode strips the location angle's fixed "Wide establishing view..." line (invites empty scenery), strips casting-pose negatives (`neutral standing casting pose`, `character sheet pose`), and adds subject-presence plus grounded-pose language.
- **Framing-aware mask sizing** (`detectIntegrateFramingIntent`): "medium shot" / "close-up" prompts enlarge the mask box beyond frame edges so crops land at the image border instead of decapitating the subject. Edge-touching box sides get zero feather.
- **Rear-view detector tightened** (`detectRearViewShot`): only explicit camera-direction phrases trigger it, and explicit "facing camera" language overrides it. Previously "window glow behind her" flipped subjects backwards.
- **Two-stage finish inside the graph**: (1) rembg subject re-composite onto the original untouched plate (erode 2px, blur 6) discards the model's reinvented background inside large mask boxes; (2) harmonization inpaint (mask grown 20px, blurred 24, denoise 0.3, plain checkpoint model, never the IP-Adapter-wrapped one) paints the boundary with diffusion: contact shadows, reflections, hair edges. Without stage 2 the result reads as green-screen compositing with a glow outline.

## 2. Scene edit mode (Qwen Image Edit 2511)

New shot reference mode **Scene edit** (`scene_edit`, template `builtin-shot-scene-edit-qwen-v1`), the recommended mode when the character must *interact* with the scene (open a door, touch objects, be occluded). Sends the location plate (image 1) and character reference (image 2) into **Qwen Image Edit 2511** with the shot prompt wrapped as an edit instruction. No IP-Adapter, no masks, no re-compositing; the model handles interaction, occlusion, lighting, and scale natively.

- Instruction suffix pins identity ("exact same face, hair, and outfit as in image 2") and architecture scale ("a doorway is taller than the person"); earlier drafts produced a red-bandana hallucination and a nine-foot door.
- Runs with the **Lightning 4-step LoRA** at CFG 1.0; ~1 minute per frame instead of ~5.5.
- **Known ComfyUI bug**: unscaled fp8 builds (`qwen_image_edit_fp8_e4m3fn.safetensors`) silently output pure noise (apply_rope regression). Use the **2511 fp8mixed** build.
- Worker fails loudly if either input upload is missing; ComfyUI's fixed input filenames would otherwise silently reuse a stale image (this was the "wrong character state appears in renders" bug).

## 3. Face detail pass (optional, Impact Pack)

New per-shot **Face detail** setting in the Visual reference panel (`faceDetail: "refine" | "off"` in shot render overrides). When on, every render chains a second pipeline stage (`face_refine`, template `builtin-shot-face-refine-v1`): Impact Pack's **FaceDetailer** detects each face (`bbox/face_yolov8m.pt` via Impact-Subpack's UltralyticsDetectorProvider), crops, upscales, re-diffuses at 0.45 denoise with a **plus-face IP-Adapter** carrying the character reference, and pastes back. Only the refined result is selectable; the base render is superseded (same pattern as the composite pipeline stages).

- **Canonical face anchor**: the likeness reference is the character's **first (default) state** cover image (the studio casting portrait), not the per-state reference, so one face anchors every outfit and scene (`resolveShotCanonicalFacePathForBatch`).
- Prefers `ip-adapter-plus-face_sdxl_vit-h.safetensors` when present; falls back to the generic plus model.
- Availability-gated: if the ComfyUI host lacks Impact Pack nodes, the pass is skipped with a console warning and shots render normally.

### Required on the ComfyUI host
- **ComfyUI-Impact-Pack** and **ComfyUI-Impact-Subpack** custom nodes (`git clone` into `custom_nodes`, then their install scripts fetch the face detector)
- Optional but recommended: `ip-adapter-plus-face_sdxl_vit-h.safetensors` in `models/ipadapter` (h94/IP-Adapter sdxl_models)

## 4. Instruction edits and Send to ComfyUI

Two actions on every completed shot candidate:

- **Edit with instruction** (`builtin-shot-image-edit-qwen-v1`): type an instruction ("change the chalkboard to read BAKERY"), the still is re-run through Qwen Image Edit as a new pack. The suffix pins everything not named in the instruction. Caveat: Qwen re-renders the whole frame, so composition can drift slightly; it is not a locked-pixels inpaint.
- **Send to ComfyUI**: copies the candidate PNG into the ComfyUI input folder (`DiffuseCutSend-<optionId>.png`) for custom workflows. Saved PNGs also embed their generating graph, so dragging one into the ComfyUI browser tab reconstructs the workflow.

## 5. Batch pipeline and UI fixes

- **`refreshBatchStatus` stage awareness**: outcome options are now computed with `filterSelectableShotOptions`; the old filter didn't know the new `base` / `face_refine` stages, so batches flipped to `awaiting_selection` the moment they started (vacuously "all complete" over an empty list).
- **Failure cascade**: when a pipeline stage fails, all queued stages that (transitively) depend on it are marked failed; previously they sat queued forever and the batch never resolved.
- **Hooks order fix**: `ShotPlaceholderOptionsPanel` had a `useMemo` below an early return, crashing React when the Shot Image Generator was collapsed. Hook moved above the return.
